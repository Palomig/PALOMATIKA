# Grade 7 Skill Bank Design

**Goal:** Convert the mixed grade 7 textbook topic bank into tutor-facing skill pages where one page trains one narrow action.

**Model:** A page is a skill, not a textbook chapter. Each skill has the same three levels: simple, medium, high. Existing Makarychev tasks are used as seeds and references, but repeated homework practice is generated by type.

**Routing:** Static production preview lives under `/alg-skills/7/`. This avoids conflicts with OGE, VPR, and the current `/alg-topics/7/0/` arithmetic prototype.

**Skill Groups:**
- Arithmetic foundation
- Algebraic expressions
- Linear equations
- Powers and monomials
- Polynomials and formulas
- Linear functions
- Systems of linear equations

**Page Contract:**
- A skill page must not mix unrelated task mechanics.
- Every page has `Простой`, `Средний`, and `Высокий`.
- Math is rendered with KaTeX.
- Multiplication is `\cdot`; division is `:`, not `/`.
- Cards must wrap text without horizontal scrollbars.

**Generated Data:** `storage/app/tasks/alg/grade_7/skills.json` is the durable skill-bank source. Static HTML is rebuilt from that file.
