# Привязка телефона: экран в два шага

**Дата:** 2026-11-25
**Статус:** дизайн согласован (выбор Стаса — «Два шага»), реализация не начата

## Задача

С 25.11 кабинет Паломатики открывается только после подтверждения номера
телефона (Flash Call Zvonok.com): пользователю звонят, он вводит последние
4 цифры номера звонящего. Через экран `/phone-login` пройдут все ранее
авторизованные — ученики, родители, репетиторы — и для каждого звонок-код
новый. С первого взгляда должно быть ясно, зачем человека остановили, что
делать и что звонок бесплатный и короткий.

## Что уже есть

- В сессии лежит `phone_challenge` (id попытки). `PhoneLoginController::form`
  показывает форму номера или поле кода, ошибки — в `$errors`.
- Лимиты: 3 звонка в час на номер, 12 на IP. Код действует 5 минут,
  5 попыток ввода.
- Гость с номером, которого нет в `phone_login_numbers`, получает «тихую»
  попытку без звонка — так нельзя перебором узнать зарегистрированные номера.
  Его экран не должен отличаться от обычного.
- На проде — оформление из коммита `a7a5bca`: карточка с декоративной полосой,
  поле без маски, код — одна строка. Второй шаг не показывает, на какой номер
  звонят.

## Принятые решения

| Вопрос | Решение |
|---|---|
| Структура | Два шага с индикатором: «Номер» → «Звонок» |
| Шаг 1: что объясняем | Зачем просят номер (один раз, около минуты, профиль на месте) и как проходит звонок — три пункта |
| Поле номера | Маска: `+7` подставляется, номер форматируется на лету, вставка `8…` и `+7…` понимается |
| Шаг 2: что видно | Номер, на который звоним, и четыре отдельные ячейки кода |
| Повторный звонок | Кнопка доступна через 30 секунд после звонка, до этого — отсчёт. Защищает от двойного звонка и расхода лимита |
| Смена номера | Ссылка «Изменить номер» раскрывает форму с текущим номером |
| Нет звонка | Сворачиваемый блок «Нет звонка?» с причинами и советами |
| Кто вошёл | В карточке строка «имя · роль» и «Выйти» — номер привязывается к нужному кабинету |
| Гость | Вместо строки пользователя — «← Другой способ входа»; подсказка, что для непривязанного номера звонка не будет |
| Без JavaScript | Страница остаётся рабочей: обычные поля, кнопка повтора доступна сразу |
| Логика звонков и лимитов | Не меняется, `PhoneLogin` не трогаем |

Роли в строке пользователя: `student` — «ученик», `teacher` — «репетитор»,
`parent` — «родитель», `admin` — «администратор». Имя — `users.name`, как в
профиле ученика.

## Визуальный язык

Нативное приложение, а не веб-форма: крупный заголовок, поле и кнопка на всю
ширину карточки, без декоративных полос и рамок вокруг каждого блока. Шрифты,
акцент и тёмная/светлая темы — токены `layouts.pwa` (Russo One, Nunito).
Второй шаг центрирован: индикатор звонка — пульсирующая иконка входящего
вызова с расходящимися кольцами.

## Экраны

### Шаг 1 — «Номер», вошедший пользователь

- Строка: `(А) Артём · ученик`, справа «Выйти».
- Заголовок «Подтвердите телефон».
- «Теперь в Паломатике входят по номеру телефона. Профиль и прогресс на
  месте — привязка займёт около минуты.»
- Три пункта: «Введите номер телефона» → «Вам позвонят. Трубку не берите —
  звонок сбросится сам» → «Введите последние 4 цифры номера звонящего».
- Поле «Номер телефона», кнопка «Позвонить мне».
- «Звонок бесплатный. Телефон с этим номером должен быть рядом — подойдёт и
  номер родителя. Один номер — один кабинет.»

### Шаг 1 — «Номер», гость

- Строка: «← Другой способ входа».
- Заголовок «Войти по телефону», «Вход по номеру, который привязан к
  кабинету.»
- Те же три пункта, поле и кнопка.
- «Звонок бесплатный, трубку брать не нужно. Номер ещё не привязан? Войдите
  другим способом — привязать его предложим сразу после входа.»

### Шаг 2 — «Звонок»

- Строка пользователя или возврата — как на шаге 1.
- Индикатор звонка: под иконкой номер и «Звоним…».
- Заголовок «Последние 4 цифры номера», «Возьмите их из входящего звонка.
  Трубку не берите — звонок сбросится сам.»
- Четыре ячейки. «Подтвердить» активна, когда введены все четыре цифры.
- «Код действует 5 минут».
- «Позвонить ещё раз» с отсчётом 0:30, ниже «Изменить номер».
- Сворачиваемый блок «Нет звонка?»: обычно звонок приходит в течение
  30 секунд; если линия занята или нет сети, он не пройдёт; определитель или
  блокировщик может скрыть незнакомый номер; пропущенный номер остаётся в
  журнале вызовов, цифры оттуда тоже подойдут.
- Для гостя в этом блоке дополнительный пункт: «Номер ещё не привязан к
  кабинету — тогда звонок не поступит. Войдите другим способом.»

### Ошибки

- Шаг 1: сообщение сервера над полем («Введите российский номер телефона.»,
  «Лимит звонков исчерпан. Попробуйте позже.», «К кабинету уже привязан другой
  номер.», «Не удалось заказать звонок. Попробуйте позже.»).
- Шаг 2: над ячейками «Код не принят. Проверьте цифры или закажите звонок
  ещё раз.» — вместо нынешнего «…и привязку номера».

## Данные

Контроллер кладёт в сессию `phone_call` — `['phone' => '+7 900 123-45-67',
'at' => время звонка]` — и передаёт в шаблон вместе с `pending`. Ключ живёт
ровно столько же, сколько `phone_challenge`: стирается при новом запросе
звонка и после успешного ввода.

Номер для показа берётся из того, что ввёл сам пользователь, а не из
`phone_login_codes`: иначе «тихую» попытку можно узнать по отсутствию номера
на экране. Остаток паузы считает сервер, поэтому перезагрузка страницы её не
сбрасывает.

Если `phone_call` в сессии нет (попытка начата до этого изменения), экран
показывается без номера и без кнопки повтора.

Тесты: после запроса звонка на втором шаге виден номер, после успешного
ввода номера на экране больше нет.

## Что сознательно не делается

- Тексты ошибок внутри `PhoneLogin` не переписываются.
- Экрана «Готово» нет: после ввода кода пользователь сразу попадает в кабинет.
- Автопроверки на четвёртой цифре нет: при лимите в пять попыток нажатие
  «Подтвердить» дешевле случайной отправки неверного кода.
- Таймера действия кода нет, только текст: звонок приходит за секунды, пять
  минут — запас.
- Кнопки «Войти по телефону» на страницах входа (`auth.login`,
  `pwa.shared.login`, `parent.home`) не оформляются — отдельная задача.
- Обещания «если ответите, робот продиктует код» нет: у Zvonok это заявлено
  в общем виде, для нашей кампании не проверено.
