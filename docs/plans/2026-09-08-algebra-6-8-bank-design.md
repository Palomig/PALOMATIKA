## Цель и границы

Учитель выбирает задания по навыкам и уровню, добавляет их в существующий урок и выдаёт домашку обычным способом. Банк включает арифметическую основу, алгебру и текстовые задачи; геометрия исключена. Графики функций относятся к алгебре и остаются. Автоматическая диагностика и расчёт освоения не входят в этот этап.

Классы — рекомендуемые фильтры доступности материала, а не запрет повторять базу. Приведённое распределение является рабочим педагогическим ориентиром, не сверкой с конкретной школьной программой. Кубы суммы/разности, системы с тремя переменными, параметры и олимпиадные техники не входят в основной объём; при необходимости это отдельное расширение.

## Шесть уровней

| Уровень | Педагогическое отличие |
|---|---|
| 1 — Первые шаги | Одно явное действие, минимальные вычислительные помехи |
| 2 — Закрепление | То же действие с вариациями знаков, чисел и расположения элементов |
| 3 — Несколько шагов | Последовательность знакомых преобразований, порядок действий |
| 4 — Сочетание навыков | Основной навык плюс дополнительные преобразования |
| 5 — Сложные комбинации | Выбор способа, вложенность, ограничения, несколько связанных преобразований |
| 6 — Нестандартные | Обратная постановка, поиск ошибки, обоснование, исследование |

Уровень относителен к навыку и prerequisites. Он не равен классу, числу тегов или величине коэффициентов. Простая комбинация может иметь уровень 2–3. Уровень 6 не требует выхода за знания 8 класса. Не заполнять шесть уровней искусственно: если высокий уровень узкого навыка имеет смысл только в комбинации, показывать соответствующие смешанные задачи, а не дубликаты.

## Комбинированные задания

Задача хранится один раз, имеет один основной навык и дополнительные навыки. В поиске «уравнения + степени + дроби» по умолчанию требуется наличие всех выбранных навыков; режим «любой из выбранных» задаётся явно. Теги отражают действия решения, а не наличие символа: $x^2$ в записи ещё не означает тренировку свойств степеней.

Различать вычисление числовой степени и преобразование буквенных степеней. «Дроби» в фильтре раскрываются на числовые и алгебраические; скобки — на числовые и буквенные. Первые комбинации:

| Сочетание | Тип задания |
|---|---|
| Знаки + дроби + порядок действий | Числовое выражение в несколько действий |
| Скобки + дроби + подобные | Упростить буквенное выражение |
| Уравнения + скобки + дроби | Найти корень линейного уравнения |
| Уравнения + числовые степени + дроби | Смешанный пример из таблиц выше |
| Степени + одночлены + дроби | Упростить частное произведений |
| ФСУ + разложение + алгебраические дроби | Сократить выражение с сохранением ОДЗ |
| Корни + ФСУ + дроби | Упростить выражение с радикалами |
| Проценты + уравнение | Восстановить исходную цену после изменения |
| Текст + дроби + система | Составить и решить модель совместной работы |
| График + линейное уравнение | Найти и объяснить точку пересечения |

Для ошибки в смешанной задаче нельзя автоматически объявлять все участвующие навыки слабыми. Такие выводы требуют отдельной диагностики и не входят в создание банка.

## Разнообразие и объём

Плановый ориентир первой большой версии — 6–10 тысяч проверенных заданий; точный объём получается после пилота. Это не обещание уже готового банка и не квота на каждый навык. Для частых навыков — ориентировочно 5–8 различных конструкций на применимый уровень, 8–12 числовых вариантов на конструкцию. Для доказательств, обратных и текстовых задач важнее разнообразие постановок, чем одинаковая численность.

Сначала три пилотных семейства: скобки, линейные уравнения, степени, плюс их комбинации. Следом арифметические пробелы, многочлены и ФСУ; затем дроби, корни и уравнения 8 класса; далее функции, неравенства, системы и текстовые задачи.

Конструкция — не простая замена чисел: неизвестное может стоять иначе, ответ быть целым или дробным, уравнение иметь один/ноль/бесконечно много корней, условие требовать прямого или обратного действия. Не делать специальные случаи там, где они меняют заявленный учебный тип без соответствующей маркировки.

## Контракт данных и проверка

Новые задания: стабильный `id`, `primary_skill_id`, `secondary_skill_ids`, `difficulty` 1–6, `recommended_grades`, `prerequisite_skill_ids`, `template_id`, `template_version`, `seed`, условие, тип ответа, точный ответ, краткое решение, ограничения/ОДЗ, происхождение и статус проверки. У конструкции должны быть педагогическое описание, допустимые параметры и запрещённые вырожденные случаи. Различать `draft`, `verified`, `published`.

Типы ответа: число/рациональное число, алгебраическое выражение, множество корней, промежуток, несколько частей, свободное объяснение. В v1 задания с неподдерживаемым автоматической проверкой типом проверяет учитель по решению/фото; интерфейс явно показывает этот режим. Эквивалентные выражения нельзя сравнивать как строки. Старые поля и ссылки читаются адаптером, новые идентификаторы не зависят от номера позиции.

Генерация детерминированная, готовые задания сохраняются до выдачи. Ответ проверяется независимым от фабрики вычислением; для уравнений — подстановкой и полнотой множества корней, для дробей — ОДЗ, для преобразований — символическим упрощением с ограничениями. Несколько числовых подстановок не являются доказательством тождества. Для текстовых задач проверяются смысл, единицы, реалистичность и непротиворечивость данных. Графики — соответствие формулам. Каждая конструкция требует просмотра представительных и граничных примеров.

## Включение в урок

Путь: «Навыки → класс/все классы → раздел → навык → уровни → карточки → добавить». Комбинации доступны дополнительным фильтром навыков. На карточке видны уровень, сочетание навыков, условие и режим проверки; ответ и решение доступны учителю. Показать число разных конструкций отдельно от общего числа вариантов. Переключатель «разные типы / все варианты» использует явный template_id, а не эвристику строки.

Не заставлять выбирать класс повторно ради базовой темы. Сохранить выбранные задания при смене фильтра. Урок хранит привычный снимок условия и ответа плюс стабильный источник и теги; последующая правка банка не меняет прошлые уроки. Новые уровни не ломают существующие ссылки simple/medium/high. Публикация только после проверки выдачи, добавления на урок и сохранения снимка.

## Критерии готовности пилота

- Есть содержательно разные задания всех шести уровней в трёх семействах, включая ручную проверку объяснения.
- Комбинация уравнения/степени/дроби находится по всем трём навыкам и имеет один ID.
- Математическая проверка выявляет неверный ответ, потерю ОДЗ, повтор варианта и случай вырождения шаблона.
- В конструкторе выбираются шесть уровней, задача добавляется и открывается у ученика.
- Старый урок со старым ID и уровнем продолжает открываться.
- Учитель видит выборку конструкций и оценивает педагогическое разнообразие перед массовым наполнением.
