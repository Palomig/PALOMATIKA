# Заметки по ученику на странице урока + сворачиваемые блоки в карточке — дизайн

Дата: 2026-07-25. Обсуждено со Стасом, решения зафиксированы.

## Проблема

Заметки об учениках (`student_notes`) пишутся прямо на уроке — шторкой «📝 Заметки» и
кнопкой «не понимает» на задаче. А посмотреть записанное можно только в карточке ученика:
уйти со страницы урока, найти ученика, вернуться. Во время урока это не работает.

## Решения (со Стасом)

- **Объём:** вся история заметок по ученику, свежие сверху; заметки текущего урока помечены.
- **Вход:** тап по имени в чипе участника (блок «Код урока»), рядом счётчик `📝 N`.
- **Видимость:** только свои заметки (`teacher_id` = текущий учитель). Записи других
  учителей об этом же ученике не показываем — так же, как в карточке ученика.
- Правку/удаление в шторку НЕ выносим: они есть в карточке ученика, на уроке нужна скорость.

## Архитектура

### API

`GET /lessons/{id}/students/{studentId}/notes` (`TeacherLessonController::studentNotes`):

- урок не мой → 403 (через существующий `loadOwnSession`);
- ученик не участник урока → 422 (`isParticipantId`, как в `notes()`);
- отдаём `{student: {id, name}, notes: [...]}`, лимит 50, `ORDER BY created_at DESC`;
- поле заметки: `id, body, kind, topic_tag, task_ref, source, lesson_session_id,
  is_current_lesson, created_at (d.m.Y)`.

### Счётчик на чипе

В `state()` у каждого участника добавляется `notes_count` — одним групповым запросом
(`student_notes` where `teacher_id` = мой and `student_id in (...)` group by `student_id`).
Отдельных запросов не появляется: `state` уже опрашивается поллингом.

### UI (lesson-prep.blade.php)

- Имя в `.participant-chip` становится кнопкой; при `notes_count > 0` рядом `📝 N`.
- Тап открывает шторку `.ns-sheet` в режиме просмотра: заголовок «📝 Имя», список записей
  «24.07 · этот урок · тема 23» + текст, бейдж вида заметки.
- Бейджи те же, что в карточке ученика (🔴 западает / 🟢 сильная / 📌 todo / 💬 общее) —
  иначе один и тот же `kind` выглядел бы по-разному на двух экранах.
- Внизу «＋ Заметка про {имя}»: закрывает просмотр, открывает форму записи с уже
  отмеченным учеником.
- Пусто → «Заметок пока нет» и та же кнопка. Грузим по тапу, не заранее.

### Карточка ученика (student-profile.blade.php)

Блоки «История вариантов» и «Темы/задания: точность» сворачиваются по клику на заголовок
(`<details>`/`<summary>`, без JS). Оба по умолчанию раскрыты — сворачивание нужно, чтобы
дотянуться до «Наблюдений» внизу, а не чтобы прятать данные при первом заходе.

## Крайние случаи

- У ученика нет заметок → пустое состояние, счётчик на чипе не рисуем.
- Заметка без `topic_tag` → мета-строка только с датой и пометкой урока.
- Ученик отпущен с урока (`released`) → остаётся в участниках, заметки доступны.
- Сеть отвалилась при загрузке → текст ошибки в шторке, повтор по кнопке.

## Тесты

- `studentNotes` отдаёт только заметки текущего учителя (чужие не видны).
- Чужой урок → 403; ученик не участник → 422.
- Порядок: свежие первыми; `is_current_lesson` верен для заметок этого урока.
- `state` содержит `notes_count` по каждому участнику.
