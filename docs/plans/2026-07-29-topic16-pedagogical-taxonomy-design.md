# Педагогическая группировка темы 16 ОГЭ

## Цель

Перестроить тему 16 «Окружность» так, чтобы каждая группа соответствовала
одному основному факту, теореме или формуле. Группы должны идти от базовых
знаний к составным задачам и одинаково отображаться в банке заданий и в
выборе заданий для урока.

Пилот охватывает только тему 16. Остальные темы сохраняют текущую группировку
ФИПИ.

## Текущее состояние

На проде тема содержит 322 задачи в 20 группах. Порядок наследуется от
`subtype_id` выгрузки ФИПИ, а названия берутся из `subtype_title`.

Исходные группы не являются учебной классификацией:

- «Касательная к окружности (квадрат)» содержит задачу на теорему Пифагора;
- «Диагональ квадрата и описанная фигура» объединяет три разных способа
  решения;
- «Площадь треугольника и равносторонний треугольник» объединяет три формулы;
- «Центр на стороне треугольника» содержит также вписанные четырёхугольники;
- «Радиусы описанных окружностей» смешивает прямые и обратные задачи для
  квадрата и равностороннего треугольника;
- одинаковые задачи на равносторонний треугольник находятся в разных группах.

## Принцип классификации

Одна группа соответствует одному ключевому знанию. Прямые и обратные задачи
можно объединять, если они используют одну формулу. Задачи разделяются, если
для их решения требуются разные теоремы, даже когда исходный подтип ФИПИ у них
одинаковый.

Внутри одной группы сохраняется порядок вариантов ФИПИ. Между группами
используется учебный порядок: базовое свойство, его прямое применение, затем
комбинации с другими знаниями.

### 2. Вписанные четырёхугольники

### 4. Описанная окружность

20. Центр на гипотенузе: найти сторону по теореме Пифагора — 10.
21. Расширенная теорема синусов — 9.

Итого: 23 группы, 4 раздела, 322 задачи.

## Хранение классификации

Курируемая карта темы 16 хранится в репозитории Palomatika. Каждая задача
привязывается к группе по стабильному GUID ФИПИ. Для группы задаются:

- постоянный ключ;
- сквозной номер от 1 до 23;
- номер и название учебного раздела;
- название группы;
- ожидаемое количество задач.

Импорт ФИПИ применяет карту только к теме 16. Для остальных тем сохраняется
группировка по `subtype_id`.

Прямая ручная правка строк на проде не используется: результат должен
воспроизводиться при каждом повторном импорте банка.

## Поток данных

1. `tasks:import-fipi` читает выгрузку ФИПИ.
2. Для темы 16 импортатор находит GUID каждой задачи в курируемой карте.
3. Задачи собираются в 23 группы в заданном учебном порядке.
4. Группы записываются в четыре блока `task_groups`.
5. `TaskBankRepository` возвращает блоки в порядке `position`.
6. Банк заданий и `LessonTaskPickerService` получают одинаковые номера,
   названия и порядок.

Старые уроки, домашние задания и результаты не изменяются: они хранят снимок
задания, а не ссылку на новую позицию группы.

## Проверки и ошибки

Импорт темы 16 должен завершаться ошибкой до записи данных, если:

- GUID отсутствует в карте;
- GUID указан более одного раза;
- в карте есть GUID, отсутствующий в выгрузке;
- фактическое количество задач в группе не совпадает с ожидаемым;
- итог не равен 23 группам и 322 задачам.

Таким образом новая задача ФИПИ не попадёт молча в случайную группу.

## Тестирование

Автоматические тесты проверяют:

- полное и однозначное покрытие 322 GUID;
- 23 группы и четыре блока в утверждённом порядке;
- названия и ожидаемые размеры всех групп;
- идемпотентность повторного импорта;
- сохранение прежнего поведения для остальных тем;
- выдачу тех же названий и порядка в банке и picker урока;
- добавление в урок задач из разделённых и объединённых групп с условием,
  ответом и SVG.

После выкладки выполняются повторный импорт, `deploy:refresh` и продовый
smoke-тест через QA-учителя.

## Откат

Карта применяется только при наличии классификации для темы. Откат состоит
из возврата импортатора к группировке по `subtype_id` и повторного импорта
банка ФИПИ. Снимки уже созданных уроков и результатов при этом не меняются.
