# Два уровня ЕГЭ в student-PWA — дизайн

**Дата:** 2026-08-29

**Статус:** утверждено Стасом

**Полное ТЗ:** https://palomig.ru/preview/ege-levels-tz/

## Цель

Сделать уровень ЕГЭ режимом всего раздела `/ege-app`: профиль и база должны иметь собственные полный вариант, мини-ЕГЭ, банк заданий, незавершённые попытки и понятные подписи в истории.

## Архитектура

Остаётся один комплект контроллеров, сервисов и Blade-шаблонов. Уровень `prof|base` резолвится в одном месте с приоритетом `?level=` → `users.ege_level` → `prof`, после чего передаётся во все операции. Явный выбор ученика сохраняется в профиле; режим просмотра учителем или администратором профиль не изменяет.

Банки остаются раздельными: `ege` для профиля и `ege_b` для базы. В `oge_variants` добавляется индексируемая колонка `level`; значение также сохраняется в `config_json.level` для совместимости анти-повтора и старых попыток.

## Интерфейс

На главном экране под плиткой урока расположен сегментированный переключатель «Профиль (П) | База (Б)». Переключение выполняется обычным GET на `/ege-app?level=…`, чтобы весь экран пересобирался сервером. У выбранного уровня одна плитка полного варианта, одна плитка мини-ЕГЭ и свой вход в банк заданий.

Мини-ЕГЭ открывается шторкой в визуальном языке существующего student-PWA. Профиль предлагает 1-ю часть (5 из 1–12), 2-ю часть (3 из 13–19), геометрию (1, 2, 3) и смешанный режим (5 из 1–19). База предлагает практические задачи (5 из 1–8), геометрию (9–13), вычисления и алгебру (5 из 14–21) и смешанный режим (5 из 1–21).

## Поведение данных

- Полный профиль содержит номера 1–19, полная база — 1–21.
- Варианты используют только `production` и предпочитают ещё не решённые задачи своего уровня.
- После исчерпания свежих задач сервис снова выбирает из production-пула; номер не исчезает из варианта.
- Активные попытки на главном экране фильтруются по выбранному уровню.
- Общая история не фильтруется, но каждая попытка получает подпись с уровнем и режимом.
- Старые ЕГЭ-варианты без уровня считаются профильными.

## Надёжность

Миграция бэкфиллит уровень существующих ЕГЭ-вариантов. Тесты покрывают резолвинг и сохранение выбора, разделение банков, полный и мини-варианты, фильтрацию активных попыток, доступ по классу, исключение черновиков и подписи истории. Затронутые feature/unit-тесты выполняются до общего релевантного набора.
