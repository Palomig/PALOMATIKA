# Домашка по итогам урока — дизайн

Дата: 2026-07-23. Обсуждено со Стасом (подход A утверждён).

## Идея

На учительской странице урока — кнопка «Домашка по уроку»: система предлагает задания,
аналогичные разобранным на уроке, учитель отмечает нужные и отправляет как обычное ДЗ
участникам урока.

## Решения (зафиксированы с Стасом)

- **Одна общая домашка на всех** выбранных учеников (без персонализации по ошибкам — later).
- **Кнопка на странице урока (lesson-prep)**, доступна в live и ended.
- **Тип ДЗ — `topic_photo_practice`** (ответ + фото решения): весь ученический флоу готов.
- **Получатели**: участники урока предотмечены, галочками можно исключать/добавлять любых
  привязанных учеников.

## Определение «аналогичного»

Задача урока хранит `bank` + `task_ref {topic_id, zadanie_number, task_id}` (+ `grade` для
ВПР/алгебры). Аналог = другая задача **того же задания той же темы того же банка**
(sibling по `task_id`), не использованная на уроке.

## Архитектура

### Эндпоинт предложений

`GET /lessons/{id}/homework-suggestions` (teacher-роут, владелец урока).

1. Задачи урока группируются по `(bank, grade?, topic_id, zadanie_number)`.
2. Для каждой группы через соответствующий TaskDataService достаются все задачи задания,
   исключаются `task_id` с урока.
3. Ответ: группы `{label: "ОГЭ · Тема 23 · Задание 4", lesson_stats: {task_count, solved},
   suggestions: [{ref, preview_text, preview_svg?}], no_analogs: bool}` + список участников
   урока. `lesson_stats.solved` — из имеющегося грида ответов. Персональные задачи учеников
   участвуют наравне с общими.

### Модал на lesson-prep

- Кнопка «📚 Домашка по уроку»; задизейблена, если задач в уроке нет.
- Группы-спойлеры с карточками-аналогами (KaTeX/SVG превью) и чекбоксами.
- Быстрые действия: «по 2 в каждой группе», «снять всё»; счётчик выбранного.
- Блок получателей: участники предотмечены + остальные привязанные ученики.
- Дедлайн — опционально, как в обычном ДЗ.
- Если по уроку уже отправлялось ДЗ — плашка «уже отправлено ДЗ N» (создание второго не
  блокируется).
- Отправка заблокирована при 0 задач или 0 учеников.

### Отправка

POST в существующий флоу назначения из пикера: `picker_tasks = [{bank, refs}]` +
`student_ids` (+ deadline) → `TeacherController::assignFromPicker` →
`TaskBankResolver::resolve()` → одна запись `homeworks` (`topic_photo_practice`,
автоназвание «ДЗ по уроку 22.07 — темы 23, 15») + снапшоты `homework_topic_tasks` +
`homework_assignments` на каждого. Для связи с уроком — колонка
`homeworks.lesson_session_id` (nullable FK, миграция) — нужна и для плашки «уже отправлено».
В ответ — ссылка на раздел «Домашка».

## Крайние случаи

- Все аналоги задания исчерпаны на уроке → группа с пометкой «аналогов нет».
- Урок без задач → кнопка задизейблена.
- Ученик отвязался от учителя между уроком и отправкой → фильтруется на бэке (как в
  обычном assign).
- Задача пропала из JSON-банка → `TaskBankResolver` её пропускает (существующее поведение).

## Тесты

- Юнит: группировка задач урока, исключение использованных `task_id`, `no_analogs`.
- Фича: эндпоинт предложений (структура, права: чужой урок — 403);
  полный цикл «выбрал → отправил → создан homework c `lesson_session_id`, assignments у
  выбранных учеников, снапшоты корректны».
