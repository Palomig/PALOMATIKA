**Agent Board:** эпик #44

## Контекст

Уходим от концепции пазлов и фокуса на учениках как платящих пользователях. Основная аудитория — ученики (бесплатно), монетизация позже через учителей и репетиторов.

## Старая концепция (устарела)

- Ученик = платящий потребитель (подписки 399–1199 ₽/мес)
- Геймификация в стиле Duolingo (стрики, бейджи, лиги, дуэли, XP, командные челленджи)
- Пазлы — уникальная механика решения (собирай решение из блоков)
- Система весов навыков и адаптивная диагностика
- AI-помощник (платный аддон)
- Бесплатно для учителей

## Новая концепция

- **Ученики** — бесплатно решают задачи
- **Учителя/репетиторы** — будущий платящий клиент (монетизация — отдельный эпик после стабилизации продукта)
- Просто банк заданий + конструктор работ
- Никаких Duolingo-механик
- Никаких пазлов

## Дорожная карта эпика #44

Подзадачи создаются в Agent Board (project=palomatika) с пометкой "эпик #44" в описании.

1. **Аудит зависимостей** — read-only обзор: где в коде используются step_blocks, badges/leagues, subscriptions, AI-помощник; что сломается при удалении. Result: чеклист точек правки.
2. **Выпил пазлов** — модели + контроллеры + views + миграции drop. Самый большой кусок.
3. **Выпил геймификации** — badges/leagues/duels/streaks/gifts/star_transactions, без затрагивания мини-игр.
4. **Стабилизация мини-игр** — PracticeLeaderboardService после выпила лиг: лидерборд с разделениями Все / Группа / Класс / Школа.
5. **Выпил биллинга** — drop subscriptions/payout_items/teacher_payouts, чистка кода.
6. **Выпил AI-помощника**.
7. **Чистка маркетинга/онбординга** — лендинг, копирайт, скриншоты, упоминания пазлов и подписок.
8. **Обновление product KB** — `.claude/product/OVERVIEW.md`, modules.

## Принципы исполнения

- Делать строго по подзадачам, не объединять — у каждой свой PR.
- Перед каждой миграцией drop — backup нужных данных в `storage/app/backups/redesign-44/`.
- Реферальная программа и parent app — **trip-wires**: не трогать без явного указания.
