# Урок v2: picker как база заданий, вход по коду, лок на 60 минут

> Дизайн утверждён Стасом 2026-07-16. Три связанных изменения модуля живого урока
> (см. `.claude/product/modules/lessons.md`). Реализация — по отдельному implementation-плану.

## Требования (зафиксированы в обсуждении)

1. Выбор заданий для урока — интерфейс ровно как база заданий в приложении,
   плюс выбор конкретных примеров или целого блока задания. Новый picker
   сразу используется и в создании ДЗ (общий компонент).
2. Вход ученика в урок — только по 4-значному коду, который генерируется
   при создании урока и показывается учителю. Инвайт-ссылки и автодобавление
   из слота расписания убираются.
3. После входа ученик заперт на странице урока 60 минут (лок): не может
   пользоваться другими страницами приложения. Учитель может вручную
   отпустить конкретного ученика.

## 1. Picker заданий (общий для урока и ДЗ)

Подход: расширение текущего JSON-picker'а (Alpine + `LessonTaskPickerService`),
карточки верстаются 1-в-1 по стилям страниц базы. Выбран вместо
server-rendered страниц (медленная навигация, корзина в localStorage)
и fetch-HTML-фрагментов (хрупкая поддержка).

### Навигация

```
Шаг 0. Класс: [7] [8] [9*]                ← 9 по умолчанию
Шаг 1 (9 класс). Раздел: [1я часть] [2я часть] [Новые задания]
Шаг 2. Пилюли тем: part1 → 06–19, part2 → 20–25, new → 09,10,15,16,17
Шаг 3. Спойлеры заданий-блоков («Задание 1. ФИПИ (24)») + карточки задач
```

7/8 классы — текущий drill-down по навыкам (alg-skill), внутри того же компонента.

### Выбор и корзина

- Тап по карточке — выбрать/снять пример.
- Кнопка «весь блок» на спойлере задания — выбрать/снять все задачи блока.
- Sticky-панель «Выбрано N · Добавить».
- Корзина в Alpine-состоянии, НЕ сбрасывается при переходах между
  классами/разделами/темами — можно набрать задачи из разных частей
  и добавить одной кнопкой.

### Бэкенд

- `GET /lessons/picker-options` получает параметр `section` (`part1|part2|new`).
- `LessonTaskPickerService` отдаёт темы раздела и задачи с полным контентом
  для карточек (svg/image, text, expression, options, answer, group_key =
  задание-блок). Источники данных — те же, что у страниц базы
  (`TaskDataService`; part1 = `Pwa/StudentController::tasksPart1`,
  part2 = `::part2`, new = `::newTasks`).
- Сохранение: блок раскрывается в отдельные `{bank: 'oge', refs}` —
  схема БД урока (`lesson_session_tasks`) и ДЗ (`homework_topic_tasks`)
  не меняется.
- `TaskBankResolver` учится резолвить задачи 2-й части (bank остаётся `oge`).
- Эндпоинт остаётся под `role:teacher,admin` (отдаёт ответы задач).

### 2-я часть на уроке (v1)

Обычное текстовое поле ответа. Где эталона нет (доказательства, тема 24) —
учитель видит ответ ученика без ✓/✗ и оценивает сам. Отдельный способ ввода
ответа для 2-й части — открытая тема, вынесена в Obsidian:
`PALOMATIKA/Задачи/Ввод ответа для 2 части на уроке.md`.

## 2. Вход по 4-значному коду

- Колонка `lesson_sessions.join_code` (4 цифры): генерируется при создании
  сессии, уникальна среди сессий в статусе `draft|live` (после `ended`
  код освобождается). Показывается учителю крупно на prep-экране.
- Student PWA: плитка «УРОК» → экран с полем ввода кода →
  `POST /lessons/join {code}` → создаётся participant, редирект на урок.
- Удаляется: `LessonJoinController` + роут `/lesson/join/{token}`,
  `invite_token`, автодобавление участников из слота. Создание сессии
  из слота остаётся (привязка к расписанию), но участники входят только кодом.
- Войти может любой авторизованный ученик, знающий код.

## 3. Лок на 60 минут

- `lesson_session_participants` + колонки: `locked_until`
  (= момент входа + 60 мин), `released_at`, `released_by` (nullable).
- Новый middleware на student-роуты PWA (кроме страницы урока, её API
  и logout): активный лок (`locked_until` в будущем, `released_at` null,
  сессия не `ended`) → redirect на страницу урока.
- Лок снимается: по истечении 60 минут / при завершении урока учителем /
  вручную — `POST /lessons/{id}/participants/{studentId}/release`
  (кнопка «Отпустить» у ученика в live-гриде).
- Ученик видит таймер обратного отсчёта на странице урока.
- Cron автозакрытия сессий (3 часа) остаётся страховкой.

## 4. Тесты

- Обновить существующие тесты урока (join-flow меняется):
  `LessonSessionServiceTest`, `TeacherLessonControllerTest`,
  `StudentLessonControllerTest`, `LessonSessionFlowTest`.
- Новые: вход по коду (верный/неверный/завершённый урок), middleware лока
  (redirect, истечение, release, снятие при end), picker-options по разделам,
  добавление блоком, создание ДЗ через новый picker.

## Вне скоупа этой итерации

- Отдельный способ ввода ответа для 2-й части (тема в Obsidian).
- Push-уведомления о старте урока, история уроков, WebSocket вместо polling.
