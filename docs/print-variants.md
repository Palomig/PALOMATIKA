# Печатные варианты ОГЭ

Генератор собирает из банка заданий готовые к печати работы — такие же, какие
ФИПИ раздаёт на тренировочных экзаменах. Один вариант — один PDF формата A4,
плюс общий файл с ключом ответов.

```bash
php artisan oge:print --count=30 --seed=2026 --first=1
```

## Откуда что берётся

| Что | Источник |
|-----|----------|
| Текст задания, формулы | `tasks.payload.html` — формулы уже в долларах, поэтому идут в TeX как есть |
| Чертежи | `<svg>` внутри того же html; перекрашиваются и конвертируются в PDF |
| Условие блока 1–5 | `task_intros.html` + растровые иллюстрации рядом с выгрузкой ФИПИ |
| Ответы | `tasks.answer` |
| Вёрстка | `resources/latex/oge/preamble.tex` и `params.tex` |

## Ключи команды

| Ключ | Смысл |
|------|-------|
| `--count=N` | сколько вариантов собрать |
| `--seed=N` | базовый seed; вариант `k` собирается из `seed+k-1` |
| `--first=N` | номер первого варианта в нумерации работ |
| `--topics=06,07,15` | только перечисленные темы |
| `--out=path` | каталог результата (по умолчанию `storage/app/print`) |
| `--title=…` | заголовок работы без номера |
| `--no-pdf` | собрать только `.tex`, не запускать pdflatex |
| `--keep-tex` | не удалять рабочий каталог со сборкой |

Seed определяет вариант полностью: та же пара `seed`+`--topics` даёт тот же
состав заданий. Выданную работу можно перепечатать, не храня её состав в базе.

## Где это запускается

**Не на проде.** На хостинге Паломатики нет и не предполагается pdflatex —
команда рассчитана на dev-VPS или локальную машину, готовые PDF выкладываются
отдельно. Требуется:

* `pdflatex` с `cm-super`, `tikz`, `tcolorbox`, кириллическими переносами;
* `rsvg-convert` (пакет `librsvg2-bin`) — конвертация чертежей в вектор;
* сеть до `PRINT_ASSETS_URL` при первом запуске (растры кэшируются в
  `storage/app/print-assets`).

## Как устроен отбор

`PrintVariantSelector` берёт по одной задаче на тему 01–25.

**Блок 1–5 — один сюжет.** В ОГЭ первые пять заданий относятся к общему
условию: план участка, график тарифа, таблица форматов бумаги. Ключ сюжета —
GUID вводного текста (`tasks.intro_guid`), а не название задания: «План
местности» — это два десятка разных планов, и блок, собранный по названию,
состоял бы из вопросов к пяти разным картам. Из 38 сюжетов банка полных 37,
неполный отбрасывается.

**Тема 24 — доказательства.** Все 60 её заданий лежат в `draft` ровно потому,
что у них нет ответа: на экране проверять нечего. На бумаге доказательство —
нормальное задание второй части, поэтому здесь `draft` допускается, но только
при пустом ответе.

**Повторы.** Внутри пачки задача не выдаётся дважды, пока в теме есть
неиспользованные. Когда пул исчерпан, повтор разрешается — иначе на теме с
двумя задачами третий вариант молча остался бы без задания.

## Вёрстка

Метрики в `params.tex` сняты с эталонного варианта ФИПИ прямым разбором
операторов PDF, поэтому в них числа вроде `51.267pt`, а не круглые. Три вещи,
без которых совпадения с эталоном не выходит:

1. **`\tolerance=9999`.** В эталоне есть строки с межсловным пробелом 6,6bp при
   норме 3,9. На умолчании 200 TeX такие строки отвергает и рвёт абзацы иначе.
2. **Выделение в плашке — прямое начертание, не полужирное.** «БЛАНК ОТВЕТОВ
   № 1» в эталоне набран тем же шрифтом, что и колонтитул.
3. **Рамка номера с нулевой глубиной.** Иначе она добавляет 5,48bp глубины
   первой строке, и строки с «й» уезжают вниз на полтора пункта.

Сверка с эталоном — `/home/dev/oge-latex/` (там же лежат `final.py`, `diff.py`,
`words.py`, которыми снималось совпадение по словам и по пикселям).

## Условие блока 1–5

Верстается как в печатных сборниках: рисунки справа с подписями «Рис. 1/2»,
текст обтекает их слева. Экспорт ФИПИ сваливает все иллюстрации в начало
условия — если печатать так, два рисунка съедают полосу целиком, а текст
уезжает на следующую страницу отдельно от своих картинок.

`wrapfig` не умеет считать, сколько строк займёт рисунок: число задаётся
вручную. Поэтому генератор прикидывает длину абзацев по числу знаков (рядом
с рисунком строка короче — это учитывается) и, если оставшегося условия не
хватает, сначала уменьшает рисунок, а совсем не влезающий печатает обычным
блоком по центру. Без этого обтекание протекает в первое задание, и оно
печатается узкой колонкой.

**Объединения в шапках таблиц.** Экспорт теряет `colspan` и `rowspan`,
оставляя рваные строки: в шапке две ячейки, ниже пять. Форма устойчива —
20 из 24 рваных таблиц банка имеют вид «2, max−1, max, max…», — и по ней
объединения восстанавливаются. Без этого «Диаметр диска (дюймы)» встаёт над
одной колонкой вместо трёх, и таблица врёт.

## Границы

* **Растровые иллюстрации.** Условия блока 1–5 приходят с картинками ФИПИ
  (планы, фотографии печей) — своих SVG для них нет. Это то же исключение из
  правила «SVG — основа проекта», что принято для банка ЕГЭ: без чертежа
  условие нерешаемо. Растр печатается в натуральную величину и только
  сжимается, если не влезает в полосу: увеличивать экранный исходник нечего.
* **Формулы-картинки в предложении.** Часть формул ФИПИ хранит растром
  («B=195» — это картинка 60×20 px), причём экспорт вынес их из предложения
  в общий блок рисунков, оставив на месте пустой `<span></span>`. Генератор
  возвращает их обратно, но только при точном совпадении числа пустых span
  и числа мелких растров: у половины сюжетов пустой span — просто мусор
  разметки. Отличие формулы от чертежа — по натуральной высоте (порог 30pt).
* **Незнакомые символы.** Символ вне таблицы перевода заменяется на `?`, и
  команда печатает предупреждение с кодовой точкой. Так одна экзотическая
  закорючка не роняет сборку сотни работ; увиденный код надо внести в
  `HtmlToLatexConverter::escape()`.
* **Обрезанные исходники.** Часть иллюстраций ФИПИ отдаёт уже обрезанными:
  фотография шины к сюжету «Шины» приходит куском 262×101 px, где от колеса
  видна только верхняя дуга. Это состояние выгрузки, а не вёрстки —
  чинится только повторной выкачкой с ФИПИ.
* **Разрывы страниц.** Задание не разрывается вовсе: половина условия на одном
  листе, а чертёж и строка ответа на другом — лист, по которому нельзя решать.
  Запрет действует только внутри задания (`\ifogebind`); вводное условие
  переносится свободно, иначе сюжет высотой почти в полосу дал бы переполнение.
  Проверка — `scripts/print/check-splits.py`: на полосе не должно быть строк
  «Ответ:» больше, чем номеров заданий.

## Импорт вводных текстов

Вводные тексты приезжают отдельной командой — они не входили в исходный
перенос банка:

```bash
php artisan tasks:import-intros --url=https://palomig.ru/fipi-bank-export/bank_katex.json
```

Команда идемпотентна: переписывает тексты и ссылки, не плодя дублей.
