## Замечания для того, кто будет чинить

**Найденные баг-паттерны (искать и в остальных темах):**
1. Мусорные авто-ответы (длинный десятичный хвост вместо чистого).
2. Потерянный внешний корень: `√((3√2−5)²)+3√2` записан как `(3√2−5)²+3√2`.
3. Степень распалась: `√(9·5⁴)` → `√9·√54`.
4. Коэффициент уехал в степень: `25√a·12√b` → `25√(a¹²b)`.
5. Опечатка показателя: `81⁵` → `8¹⁵`.
6. Неверный оператор: `·` вместо `−`.
7. **Формат ответа по инструкции задания**: «запишите числитель несократимой дроби» / «дробь со знаменателем N» — а в базе лежал десятичный.
8. Незаполненный дефолт (`«нет в базе»`, пустая строка, или ответ-дефолт `«a»` у choice).
9. **Скрытые ошибки**: даже «чистый» числовой ответ бывает неверным — проверять КАЖДУЮ задачу, а не только подозрительные.

**Технический подводный камень:** JSON с полем `svg`/`image` (темы 07, 11, 15–18, 24…) править **только точечно** по сырому тексту (`re.sub` по уникальному якорю). НЕ использовать `json.load`+`json.dump` — Python переэкранирует слэши в SVG (`\/`→`/`) и создаёт гигантский ложный diff.

**Метод сверки:** `pdftotext` коверкает математику (теряет √, степени) — страницы PDF читать ВИЗУАЛЬНО. Структура совпадает: PDF Блок→Задание→подпункт = JSON block→zadanie.number→task.id (кроме Блок 1 темы 08, где нумерация сдвинута — матчить по содержимому).
