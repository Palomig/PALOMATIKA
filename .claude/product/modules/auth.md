# Авторизация

Вход по телефону проходит через Flash Call Zvonok.com. Telegram и другие настроенные способы входа доступны для первого входа. `RequireVerifiedPhone` отправляет авторизованных пользователей без записи в `phone_login_numbers` на `/phone-login`.

`PhoneLoginController` хранит в сессии `phone_challenge` и `phone_call`. Первый шаг принимает номер, второй показывает номер и принимает последние четыре цифры входящего вызова. JavaScript добавляет маску номера, отдельные ячейки кода и 30-секундный таймер на кнопке повторного звонка. Сервер проверяет код в течение пяти минут и допускает до пяти попыток. Формы работают без JavaScript.

При изменениях проверить привязку к текущему кабинету, повторный вход, неверный код и работу форм без JavaScript. В серверном сервисе `PhoneLogin` действуют почасовые лимиты на звонки.
