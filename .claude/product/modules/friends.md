# «Позови друга»

Ученик приводит друга с собой на **бесплатное первое занятие в группе** (офлайн). Ссылок и лендингов нет: кто привёл, говорит сам новичок на первом занятии, преподаватель записывает сразу. Задним числом не меняется.

## Две акции (по классу пригласившего)

| | 8–11 класс (`cash`) | 6–7 класс (`discount`) |
|---|---|---|
| Награда | 2000 ₽ наличными за друга | −50% на следующий месяц пригласившему **и** приглашённому |
| Бонус | +3000 ₽ за каждого третьего друга | — |
| Когда | друг оплатил месяц занятий | друг оплатил месяц занятий |
| Общий друг (до 3 пригласивших) | 2000 ₽ делятся поровну | скидку получает каждый |
| Страница | `pwa.student.friends` | `pwa.student.friends-discount` (текст для родителей) |

Смешивать 6–7 и 8–11 в одной записи нельзя. 5 класс и младше в акции не участвуют.

**Порог бонуса в коде — каждые 6000 ₽ заработанного**, а на экране — «третий друг». Иначе сплит превращается в сговор: двое, записывающие друг другу всех подряд, дойдут до бонуса только после шести реальных друзей.

## Гейт

Только прикреплённые к учителю (`teacher_students`) ученики нужных классов и админ (превью; `/friends?program=discount` — страница 6–7). Паломатикой пользуются посторонние через открытые банки — показать им 2000 ₽ нельзя.

## Где что

- `App\Services\FriendInviteService` — вся логика и константы
- Полоска под плиткой «УРОК» — `partials/friend-strip`, данные через view composer в `AppServiceProvider` (обёрнут в try/catch: промо не должно ронять главный экран)
- Кабинет учителя `teacher.palomatika.ru/friends`: запись новичка → «Остался: оплатил месяц» / «Не остался» → «Выдал» (деньги) или «Применил» (скидки)
- **Доски зовущих ведутся вручную** супер-админом (`User::isSuperAdmin()`, `config/palomatika.php` → `SUPER_ADMIN_IDS`, по умолчанию id 1), своя у каждой акции; имя на доске видно всегда (скрытие убрали 30.09)

## Таблицы

`friend_invites` (program, qualified_at, cancelled_at, invitee_discount_applied_at), `friend_invite_credits` (доля/процент на пригласившего, paid_at = выдано/применено), `friend_invite_bonuses`, `friend_board_entries`, `users.invite_board_hidden`. Таблица `friend_invite_notes` осталась от убранной кнопки «Отметить, кого позвал» и не используется.

**Не путать с `users.referred_by_user_id`** — та связь привязывает ученика к учителю по ссылке-приглашению.
