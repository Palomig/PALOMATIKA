# Правила деплоя

## Деплой — ТОЛЬКО вручную, напрямую на Timeweb. Через GitHub ничего не выкатывается

- Прод выкатывается **исключительно вручную** FTP-заливкой с dev-VPS на Timeweb:
  `scripts/deploy-prod.sh` (сверка MD5 каждого файла + `deploy:refresh`). Никакой
  автоматики между git и продом **нет и не должно быть**.
- GitHub здесь — только хранение кода и авто-мёрж веток `claude/**` в `develop`
  (интеграционная песочница, не деплой). Автодеплой из GitHub Actions убран
  2026-08-07 после истории с зелёным статусом без реального трансфера —
  **не возвращать и не предлагать**.
- Пуш (в любую ветку, включая `main`) сам по себе **ничего не выкладывает**.
  «Задеплоено» = запущен `deploy-prod.sh` и все MD5 сошлись, не «запушил».
- Выкат фичи: `scripts/promote.sh claude/<фича>` (мёрж в `main` + та самая ручная
  FTP-доставка) — и только после решения Стаса.

## Осторожность
- Скрипт заливает файлы **из рабочего дерева**, а не из git-объектов — дерево
  обязано стоять ровно на деплоимой ревизии (проверка встроена, обойти нельзя).
- Не деплоить вслепую из отстающего чекаута; при сомнении сверить маркер с MD5
  на проде.

Для полной документации — используй скилл `deploy-ops`.
