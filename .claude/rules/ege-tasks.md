Разные директории, роуты, контроллеры, целевая аудитория (11 класс).

## Рисунки банка ФИПИ — PNG, и это осознанно

Общий принцип проекта «SVG — основа, никогда PNG» на банк ЕГЭ от ФИПИ **не
распространяется**: решение Стаса от 2026-08-07. В ОГЭ каждый растр заменён
своим SVG, но их рисовали месяцами; для ЕГЭ таких SVG нет, а без чертежа
условие нерешаемо.

Файлы лежат в `public/ege-bank/img`, раскладывает их
`php artisan tasks:import-fipi-ege --images=…`. В разметке у каждого растра
класс: `fipi-figure` — самостоятельный чертёж (белая подложка), `fipi-inline`
— обозначение внутри предложения («SABCD», «AM = 2»), выводится строкой.
Класс проставляет экспорт по натуральной высоте растра — CSS её не знает.

Не заменять эти картинки «нарисованными SVG» без отдельного решения.

## Критические ограничения
- Номера заданий = номерам в PDF — **НЕЛЬЗЯ менять**
- `*_geometry.json` для ЕГЭ — не редактировать вручную: регенерировать через `php artisan svg:bake-ege {id}`

## После изменений
```bash
php artisan cache:clear
# Если геометрия:
php artisan svg:bake-ege {id}
```

Для полной документации — используй скилл `ege-tasks`.
