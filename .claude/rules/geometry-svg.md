# Правила при работе с geometry JSON

## Это ИСТОЧНИК — не результат
```
*_geometry.json  ← РЕДАКТИРУЙ ЗДЕСЬ
      ↓
php artisan svg:bake {id}
      ↓
topic_XX.json    ← SVG записывается сюда (не трогать вручную)
```

## После любых изменений — обязательно
```bash
php artisan svg:bake {id}   # например: svg:bake 15
php artisan cache:clear
```

## Критические правила SVG
- `max-w-[250px]` — **ФИКСИРОВАННЫЙ** размер, никогда не менять
- `viewBox` = `0 0 220 200` (стандарт)
- Фигура должна занимать ~85% viewBox
- Отступ подписей вершин: минимум 25px от края
- Подписи вершин — через `labelPos()`, никогда фиксированными координатами
- Биссектриса — только через `bisectorDirection()`, не хардкодить

## Цвета
| Элемент | Цвет |
|---------|------|
| Стороны | `#dc2626` |
| Вспомогательные линии | `#10b981` |
| Известные значения | `#f59e0b` |
| Подписи вершин | `#60a5fa` |
| Прямой угол | `#666666` |

## Рисунок = концептуальная схема, не масштабный чертёж
Радиус и положение выбираются визуально, чтобы всё влезало в viewBox.

Для полной документации (все функции, формулы) — используй скилл `geometry-svg`.
