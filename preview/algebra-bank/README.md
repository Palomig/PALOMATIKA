# Algebra bank preview

Public target: https://palomig.ru/preview/algebra-bank/

Scope: independent teacher-facing bank on palomig.ru. No writes or integration to the live palomatika.ru application. Local collection, printable/student sheets, JSON/text export. No student personal data is collected.

## Content

9,805 unique task conditions, 169 deterministic templates, 156 mapped skills, 13 sections. Six levels are present across the bank; not every narrow skill has all six populated. Difficulty labels and grade assignments are pedagogical editorial metadata, not an official curriculum alignment. Every condition is generated by own factories, not copied wholesale from a textbook. Explanations/proofs require teacher review.

Source: `scripts/algebra-bank/build.py`. Seed schedule `20260908 + seed`, seed range 0–74. Deduplication by exact prompt+math, IDs by template plus SHA-256 of condition. Public tasks omit symbolic validation checks; those are built into `scripts/algebra-bank/checks.json` for development.

## Rebuild and verify (repository root)

- `python3 scripts/algebra-bank/build.py` — Python with SymPy (tested 1.9).
- `python3 scripts/algebra-bank/verify.py scripts/algebra-bank/checks.json` — all machine-checkable mathematical certificates, including equation root sets and exclusions.
- `python3 -m unittest discover -s tests/algebra-bank -v` — catalogue, duplicates, coverage, domain and radical-form regressions.
- `node --test tests/algebra-bank/model.test.mjs tests/algebra-bank/render.test.mjs` — filters, storage, KaTeX syntax for all tasks, grade constraint. Rendering test uses installed KaTeX from `/home/dev/fipi-sync/node_modules/katex`.
- `python3 -m http.server 8947 --bind 127.0.0.1 --directory preview/algebra-bank` — local serving.
- `node tests/algebra-bank/browser.mjs` — desktop/mobile workflow. Uses installed playwright-core from `/home/dev/vpr-sync` and Chromium from `/home/dev/.cache/ms-playwright`. Override `ALGEBRA_URL` to test another deployment.

## Delivery

Copy only index.html, guide.html, style.css, app.mjs, model.mjs, bank.json and assets/ to `/var/www/html/preview/algebra-bank/` after checks pass. All runtime assets are self-hosted. Keep build code, documentation and check data out of the web directory. No Apache reload needed. Static files use Apache's normal ETag/Last-Modified revalidation; when changing module contracts, version import URLs together.

The preview stores IDs/title in localStorage. A downloaded JSON is a snapshot for archival/future integration; importing it back is not implemented. Shared sheets reference stable IDs in the published bank, and expose conditions without an answer UI. The underlying bank is public, so this is not an exam-security boundary.

## Validation limits

Algebraic expressions and numeric factories have symbolic equality checks; equations are solved independently and compared with the full permitted root set. Some text/proof/classification templates carry a mathematical certificate plus a human explanation; automatic checks do not certify pedagogy or every word of an explanation. The first published version is intended for teacher use and feedback, not automatic student grading.
